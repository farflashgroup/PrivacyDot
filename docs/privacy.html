Privacy, with the details

Your device activity
stays on your PC.

PrivacyDot observes Windows activity metadata. It collects no telemetry and uploads no microphone or camera usage.

What the application reads

Microphone detection uses active Windows Core Audio capture sessions. Camera attribution uses the Windows sensor activity monitor where available. Windows privacy usage records provide a fallback. The popup can display app names, executable paths, and device names reported on your machine.

PrivacyDot does not open a camera, capture video frames, or record audio.

What leaves the machine

The application contacts GitHub after startup and when you choose Check for updates to check the latest stable PrivacyDot release. These requests necessarily reach GitHub's infrastructure; GitHub receives the connection information associated with the request.

An installer is downloaded only after you confirm an available update. No device-usage data or telemetry is sent with update checks. See the repository's update documentation and GitHub's privacy statement for more context.

What detection can and cannot tell you

Detection is best-effort and depends on Windows and device drivers exposing activity. Gray means no activity was detected through the sources available to the app. It cannot establish that every capture path is inactive.

Per-camera attribution requires Windows 10 version 1703 or newer with the sensor activity monitor. Older Windows versions have limited camera visibility.

PrivacyDot is not an antivirus, firewall, or temporary per-app permission blocker. Its force-quit action can close matching app processes after confirmation and may lose unsaved work.

Local preferences

Language preferences are saved locally for future launches. Startup behavior is controlled through a Windows Startup shortcut. Settings provides startup, language, and update controls.

This website

This static website includes no analytics scripts, tracking cookies, external fonts, or device-access requests. It is hosted on GitHub Pages, so hosting requests are processed by GitHub. Following a GitHub download or source link takes you to GitHub.

Questions or security reports

For product questions, contact privacydot@farflash.com. For security issues, use the repository's private vulnerability reporting route. Avoid publishing private diagnostics or personal information in public issues.
