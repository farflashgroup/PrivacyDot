# Localized directory blurbs

Prepared translations for the app's eight interface languages. Use only on platforms that accept the language; AlternativeTo requires English. These are listing drafts, not published submissions. Keep platform, privacy, and detection limits with the description.

## English

**See which apps are using your microphone and camera.**

PrivacyDot is a free, open-source Windows tray utility that shows detected microphone and camera activity. Click the dot to see apps grouped by device. It collects no telemetry and uploads no device-usage data; it contacts GitHub for update checks. Detection depends on Windows and device drivers. MIT licensed.

## Français

**Voyez quelles applications utilisent votre microphone et votre caméra.**

PrivacyDot est un utilitaire Windows gratuit et open source qui affiche l’activité détectée du microphone et de la caméra dans la zone de notification. Cliquez sur le point pour voir les applications regroupées par appareil. Il ne collecte aucune télémétrie et ne transmet aucune donnée d’utilisation des appareils. Il contacte GitHub pour rechercher des mises à jour. La détection dépend de Windows et des pilotes. Licence MIT.

## Español

**Consulta qué aplicaciones usan tu micrófono y tu cámara.**

PrivacyDot es una utilidad gratuita y de código abierto para Windows que muestra la actividad detectada del micrófono y la cámara en el área de notificación. Haz clic en el punto para ver las aplicaciones agrupadas por dispositivo. No recopila telemetría ni envía datos de uso de los dispositivos. Se conecta a GitHub para buscar actualizaciones. ## 日本語

**マイクやカメラを使用しているアプリを確認。**

PrivacyDot は、検出されたマイクとカメラの使用状況を Windows の通知領域に表示する、無料のオープンソースユーティリティです。ドットをクリックすると、検出されたアプリをデバイスごとに確認できます。テレメトリの収集やデバイスの使用情報の送信は行いません。更新の確認時には GitHub に接続します。検出の可否は Windows とデバイスドライバーに依存します。MIT ライセンスで公開されています。

## 简体中文

PrivacyDot 是一款免费、开源的 Windows 托盘工具，可显示检测到的麦克风和摄像头使用活动。点击圆点，即可按设备查看检测到的应用。它不收集遥测数据，也不上传设备使用信息；检查更新时会连接 GitHub。检测结果取决于 Windows 和设备驱动程序。采用 MIT 许可证。

## العربية

**تعرّف على التطبيقات التي تستخدم الميكروفون والكاميرا.**

PrivacyDot أداة مجانية ومفتوحة المصدر لنظام Windows تعرض النشاط المكتشف للميكروفون والكاميرا في منطقة الإعلام. انقر على النقطة لرؤية التطبيقات المكتشفة مجمّعة حسب الجهاز. لا تجمع الأداة بيانات القياس عن بُعد ولا ترفع بيانات استخدام الأجهزة. تتصل بـ GitHub للتحقق من التحديثات. يعتمد اكتشاف النشاط على Windows وبرامج تشغيل الأجهزة. متاحة بموجب ترخيص MIT.

## Русский

**Узнайте, какие приложения используют микрофон и камеру.**

PrivacyDot — бесплатная утилита с открытым исходным кодом для Windows. Она показывает обнаруженную активность микрофона и камеры в области уведомлений. Нажмите на точку, чтобы увидеть обнаруженные приложения, сгруппированные по устройствам. Утилита не собирает телеметрию и не отправляет данные об использовании устройств. Для проверки обновлений она обращается к GitHub. Обнаружение зависит от Windows и драйверов устройств. Лицензия MIT.
